CSS patterns for the exam

Drag the sliders — these are live, working versions of the two layouts the brief always asks for.

2Flexbox — the featured item row

Image + text sitting side by side, with a gap between them. This is display: flex on the parent.

This box has flex: 1, so it fills whatever space is left over.
#featured {
  display: flex;
  gap: 16px;             /* space between image + text */
}
#featured img {
  width: 180px;
  height: auto;
  flex-shrink: 0;        /* stop it squashing when space is tight */
}
.featured-info {
  flex: 1;               /* take up remaining width */
}

5CSS Grid — the card grid

Uneven number of cards, always in neat columns. This is display: grid + repeat().

.card 1
.card 2
.card 3
.card 4
.card 5
#card-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);  /* 3 equal columns */
  gap: 20px;
}
.card {
  display: flex;
  flex-direction: column;   /* stack image/title/text vertically */
  background-color: #ffffff;
  padding: 20px;
  border-radius: 8px;
}
repeat(3, 1fr) in plain English "Make 3 columns, each taking an equal (1fr) share of the available width." Change the number and every card grid you build reflows automatically — you never set a card's width directly.

2 / 6Hiding and revealing with a class

Toggle the checkbox below — this is exactly the mechanism behind Task 3 and Task 6.

You only see this once the class below is added to the element.

.description {
  display: none;       /* hidden by default */
}
.description.show {    /* NOTE the dot before "show" */
  display: block;
}
The single most common CSS bug in this brief .description.show (two classes on one element) is completely different from description.show (missing leading dot — this means an element whose CSS type is literally <description>, which doesn't exist, so the rule silently never matches anything). If your toggle button changes text but nothing visually shows or hides, check this first.
