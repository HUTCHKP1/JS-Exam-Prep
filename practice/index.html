1HTML structure + featured item

header (h1) · main wraps both sections · footer (name + ID) · title · stylesheet link · script tags. Inside main: #featured and #card-grid. Build the featured item from FEATURED_RECIPE as a template literal via innerHTML.

2CSS: featured item

display: flex on #featured, gap, fixed-width cover that doesn't stretch, .description hidden by default, header/footer styling, page background. Colour table is in starter/style.css.

3JS: show more / show less

Click listener toggles a class on .description and swaps textContent. Attach it after the featured item's innerHTML is set.

4JS: fetch and render cards

async function awaits fakeFetchRecipes(), loops, builds each card with +=, assigns innerHTML once after the loop, gets called on load.

5CSS: card grid layout

#card-grid as a grid with repeat() columns and gap. Each .card a column flexbox with background, padding, radius.

6Show descriptions checkbox

Checkbox + label above the grid. change listener selects descriptions inside the handler and toggles a class on all of them.
