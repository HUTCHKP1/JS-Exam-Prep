# Exam Prep Toolkit

Revision resources for a web dev practical exam built around: a featured
item (flexbox, template literals, show/hide toggle) plus a card grid
(CSS Grid, fetch + async/await, a checkbox that toggles descriptions).

**Open `index.html` in a browser to start.** Everything is static HTML/CSS/JS
— no build step, no server, no internet required.

## What's in here

- `index.html` — hub page with links to everything + a saved task checklist
- `reference/js-cheatsheet.html` — every JS pattern the brief tends to ask for
- `reference/css-cheatsheet.html` — flexbox + grid, with live interactive demos
- `reference/dom-live-playground.html` — editable, runnable code sandboxes
- `reference/pitfalls.html` — specific bugs that actually show up in this task
- `reference/mdn-links.html` — the exact MDN / CSS-Tricks pages worth bookmarking
- `quiz.html` — 20-question self-marking recall quiz
- `practice/` — a full second mock run (different theme: recipes, not books)
  with starter files to attempt cold and a solution to check against

## Use this before the exam, not during it

If your exam rules allow local notes and sites like MDN/CSS-Tricks but not AI
tools, that's exactly the design here: everything is static reference
material and practice exercises, not a code generator. Go through it,
actually write the code yourself in the practice run, and get to the point
where you understand *why* each pattern works — that's what carries over
into the real thing tomorrow.
